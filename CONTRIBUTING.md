# Contribuindo

Abra primeiro uma [issue](https://github.com/Luizinfo/IdentityServer4/issues) para discutir mudanças relevantes. Pull requests devem preservar compatibilidade de protocolo e schema, incluir testes e compilar com o SDK .NET 10. Não inclua credenciais, dados pessoais ou material incompatível com a licença Apache-2.0.
